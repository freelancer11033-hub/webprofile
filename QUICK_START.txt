📦 INSTALLATION (5 Minutes)

1. CREATE DATABASE
   • Open phpMyAdmin
   • Create database: portfolio_db

2. CONFIGURE DATABASE
   • Edit: config/database.php
   • Update credentials:
     - host: localhost
     - database: portfolio_db
     - username: root
     - password: (your MySQL password)

3. RUN INSTALLER
   • Visit: http://localhost/portfolio/database/install.php
   • Wait for success message

4. LOGIN TO ADMIN
   • URL: http://localhost/portfolio/admin/login.php
   • Username: admin
   • Password: admin123

5. CHANGE PASSWORD!
   • Admin Panel → Profile → Change Password

🔧 TROUBLESHOOTING
═══════════════════════════════════════════════════════════════

Problem: Can't connect to database
Solution: Check config/database.php credentials

Problem: File upload fails
Solution: Make uploads/ folder writable (chmod 755)

Problem: 404 errors
Solution: Enable mod_rewrite in Apache

Problem: Admin login fails
Solution: Run install.php again or reset password in database

Problem: CSS not loading
Solution: Clear browser cache (Ctrl+F5)

💾 BACKUP INSTRUCTIONS
═══════════════════════════════════════════════════════════════

Automatic Backup:
1. Admin Panel → Backup
2. Click "Create Backup Now"
3. Download SQL file

Manual Backup:
1. Export database from phpMyAdmin
2. Copy uploads/ folder
3. Store in safe location

Restore:
1. Import SQL file in phpMyAdmin
2. Replace uploads/ folder
