🚀 QUICK INSTALLATION (5 MINUTES)

Step 1: Create Database
   Open phpMyAdmin → Create database: portfolio_db

Step 2: Update Database Config
   Edit: config/database.php
   Update: username, password if needed

Step 3: Run Installer
   Visit: http://localhost/yourfolder/database/install.php
   (Replace 'yourfolder' with your actual folder name)

Step 4: Login to Admin
   URL: http://localhost/yourfolder/admin/login.php
   Username: admin
   Password: admin123
   
Step 5: Change Password!
   Admin Panel → Profile → Update Password
