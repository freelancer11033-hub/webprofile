### 5️⃣ **Manage Blog Posts** (`/admin/pages/blog.php`)

**What you can do:**
- ➕ Create blog posts
- 📁 Organize by categories

- 🏷️ Add tags

- 📝 Draft or publish

- 🗑️ Delete posts

**How to create a blog post:**
1. Click "Blog Posts" in sidebar
2. Click "New Post"
3. **Content Tab:**
   - Enter post title
   - Select category (or create new)
   - Upload featured image
   - Write your content
   - Add tags (comma-separated)
   - Check "Publish immediately"
4. **SEO Tab:**
   - Enter meta title
   - Write meta description
   - Add keywords
5. Click "Save Post"

**How to manage categories:**
1. On Blog page, click "Categories" button
2. Enter new category name
3. Click "Add"
4. Categories appear in dropdown when creating posts

## ❓ Still Having Issues?

### If you get 404 errors:
1. Make sure `START_SERVER.bat` is running
2. Check the URL is `http://localhost:8000/admin/`
3. Run system check

### If database errors:
1. Go to `http://localhost:8000/database/install.php`
2. This creates all tables

### If images won't upload:
1. Check `uploads/images/` folder exists
2. Check folder is writable

### If pages look broken:
1. Clear browser cache (Ctrl+Shift+Delete)
2. Refresh page (Ctrl+F5)
