💡 HOW TO ADD YOUR FIRST AD:

   1. Go to: Admin → Ads Management
   
   2. Click "Add New Ad"
   
   3. Fill in:
      • Ad Name: "My First Ad"
      • Position: "Blog Sidebar - Top"
      • Type: Choose Image or Code
      • Upload image OR paste code
      • Add URL (for image ads)
   
   4. Click "Save Ad"
   
   5. View your blog to see it live!
